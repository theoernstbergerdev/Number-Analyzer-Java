# Number Analyzer (Java) 📊

A simple Java console application built to practice core programming logic, array manipulation, and input validation.

## 🎯 About the Project

This project was developed as a practice exercise to handle user input in Java, process numbers, and prevent application crashes using proper exception handling.

### What it does:
- Asks the user to input **10 positive integers**.
- Calculates the **sum** of all numbers.
- Counts how many numbers are **even** and **odd**.
- Identifies the **highest** and **lowest** values entered.
- Validates input to ensure only positive numbers are accepted.

## 🛠️ Concepts Practiced

- **Arrays:** Storing multiple user inputs.
- **Loops & Conditions:** Iterating through numbers (`for`) and logic checks (`if/else`).
- **Exception Handling:** Using `try-catch-finally` to capture `IllegalArgumentException` and `InputMismatchException`.
- **Scanner:** Reading data from the terminal.
